
# Codex Project Instructions

## Project
Personal engineering portfolio hosted on GitHub Pages.

## Goals
- Modernize the UI and UX.
- Improve accessibility and responsiveness.
- Improve project presentation and navigation.
- Improve SEO and maintainability.
- Preserve lightweight static hosting.

## Engineering rules
- Prefer HTML, CSS, and vanilla JavaScript.
- Do not introduce React, Next.js, or a backend without justification.
- Do not invent projects, experience, metrics, or achievements.
- Preserve working external links and existing content.
- Avoid unnecessary dependencies.
- Respect reduced-motion preferences.
- Use semantic HTML and accessible interactions.
- Make focused, reviewable changes.
- Never commit or push automatically.
- Run appropriate validation after changes.

## Workflow
1. Inspect the relevant code.
2. Explain the intended changes.
3. Implement the scoped task.
4. Run appropriate checks.
5. Summarize changes, tests, and remaining risks.
