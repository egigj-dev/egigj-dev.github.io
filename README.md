### Hello, I'm Egi.

I'm interested in the part of AI engineering that happens *after* a promising notebook: making models understandable, connecting them to real software, and knowing when a simpler system is the better choice.

My interests move between **NLP and retrieval**, **recommendation and predictive modeling**, and the software and infrastructure that support them.

### A few things I've worked on

| Project | What it's about |
| :-- | :-- |
| [TiranaTips](https://github.com/egigj-dev/TiranaTips) | A multilingual guide to Tirana that explores retrieval-augmented generation (RAG) for city information. |
| [real-estate](https://github.com/egigj-dev/real-estate) | A property-listing app for Tirana, using XGBoost price estimates and comparable listings to help put asking prices in context. A FastAPI backend serves the application. |
| [my-blog](https://github.com/egigj-dev/my-blog) | Writing that unpacks deep learning fundamentals, using explanations to make the ideas behind models easier to understand. |
| [notebooks](https://github.com/egigj-dev/notebooks) | Jupyter notebooks for exploring data and testing ideas through small experiments, analyses, and prototypes. |

### How I approach the work

`Question → Data → Baseline → Model → Evaluation → Integration → Iterate`

I care about good problem definitions, sensible metrics, understanding failure modes, and treating deployment and security as part of the engineering problem rather than an afterthought.

**Working vocabulary:** Python · Machine Learning · NLP · RAG · Vector Search · FastAPI · Docker · Cloud · Security
